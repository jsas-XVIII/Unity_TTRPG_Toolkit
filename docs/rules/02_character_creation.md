## Step III: Distributing Attributes

The four **Main Attributes** are:
- **MIGHT** — physical strength, hardiness, smashing, damage resistance, endurance
- **AGILITY** — grace, speed, reflexes; used for Defense Rating (DR) and Speed
- **MIND** — mental acuity, intelligence, wisdom, willpower; used for Mental Resistance (MR)
- **PRESENCE** — personal magnetism, charisma, social influence

### Attribute Distribution Arrays
Apply one of these arrays to Baseline Attributes. Each modifier is used exactly once; once applied, both the modifier and Attribute are locked.

**Option 1:** +1, +1, 0, −1
**Option 2:** +2, 0, 0, −1 (no Attribute may exceed +3 at character creation)

### Rolling for Attributes (Optional)
Roll 1d10 four times:

| Die Result | Modifier |
|-----------|---------|
| 1–2 | −1 |
| 3–6 | 0 |
| 7–9 | +1 |
| 10 | +2 |

## Combat Statistics (Derived from Attributes)

| Stat | Calculation |
|------|-------------|
| **Attack Rating (AR)** | Class Main Attribute modifier (+ class level bonuses) |
| **Defense Rating (DR)** | AGILITY modifier (+ class bonuses) |
| **Mental Resistance (MR)** | MIND modifier (+ class bonuses) |
| **Speed** | AGILITY modifier (+ class/power bonuses) |
| **Starting HP** | Class base HP + MIGHT (see class section) |
| **Recuperations** | 2 baseline + 1 per 2 MIGHT points (e.g., MIGHT 2 = +1 Recuperation) |

## Step V: Core Paths

Core Paths are a character's **background skills and experiences** — where they get their non-combat (and sometimes combat) bonuses.

### How They Work
- Roll 2d10 + [Relevant Attribute] + [Core Path Points] for skill checks
- Invoked when the Core Path is relevant to the task
- Each path has a title, brief description, and a point value (bonus)

### Starting Core Paths
- Start with **3 Core Paths**
- **5 Core Path Points** to distribute at Level 1
- Each path: minimum 1 point, maximum 3 points at Level 1
- Max 6 points on any single Core Path (across all levels)
- New paths can be created; sample paths provided in the book

### Sample Pre-Made Core Paths
- Bookworm (Deciphering, Language, Knowledge)
- Inventor's Household (Technology, Repair, Craftsmanship)
- Life of the Party (Performance, Charm)
- Fierce Competitor (Athletics, Endurance, or Intellectual competition)
- Mixologist (Alchemy, Botany, Medicine)
- Pilot (Navigation, Technology — very strong when Titan Rigs appear)
- Son/Daughter of the North (Climbing, Navigating Icy Terrain, Fishing, Shelter)
- Street Urchin (Pickpocketing, Bluffing, Intuition, Stealth)
- Wild Child (Animal Husbandry, Foraging, Hunting, Swimming)

## Step VI: Class Perks

- Each class offers **2 Class Perks** to choose from
- Select **1 Class Perk** at Level 1
- Mostly non-combat bonuses that reinforce class identity
- Additional perks unlocked via leveling (General Perks at higher levels)

### General Perks (available via leveling)
- **Combat Specialist** — +1 to Class Resource recharge rolls (+2 at Level 5)
- **Indomitable** — Death rolls use 3d10 (choose best 2); second wind HP is doubled
- **Weapons Master** — +1 damage with chosen weapon class; stackable, repeatable for other competencies
- **Jack of All Trades** — +1 to any non-highest Attribute; stackable
- **Burst of Speed** — Once per Full Rest: Movement action covers 2 range bands, immune to Provoked Attacks that round
- **Resilient** — Max HP always increased by Level + 5
- **Opportunist** — Successful Provoked Attacks deal extra HL damage
- **My Brother's Keeper** — No Provoked Attacks when stabilizing allies; stabilize rolls can Recharge; success grants Benefit on next action
- **Thrill of Battle** — Double 10s grant both Massive Hit and Adrenaline Rush (instead of choosing)
- **Seize the Initiative** — Benefit + HL bonus on all Speed checks
- **Mastery** — Once per Full Rest: reduce next power's Class Resource cost by 2
- **Snakeblood** — (implied: improves Poison/Disease resistance)

## Step VII: Class Powers

- Start with **3 Tier I Powers** at Level 1 (no upgrades at Level 1)
- **Tier II Powers** unlock at Level 5 (choose 2 initially)
- Power choices are **permanent**
- Upgrades purchased with **Tier Tokens** from leveling

### Power Card Structure
1. **Name** — power's name
2. **Action Type** — Standard, Quick, Movement, Free, Reaction, Maintain, Overdrive, or Ultimate
3. **Cost / Target / Range** — Resource cost, number of targets, range
4. **Effects** — What happens on success and failure
5. **Upgrades** — Optional modifications (purchased with Tier Tokens)

### Key Power Abbreviations
- **HL** — Half of current Level (minimum 1, round down)
- **"Roll your Basic Attack"** — Roll 2d10 + AR vs. target's DR
- **"Make a Basic Attack"** — Full Basic Attack including damage
- **"Half damage"** — Roll success damage, then halve result
- **"Half Basic Attack damage"** — Roll weapon damage, then halve result

## Step VIII: Equipment

- Starting wealth: **150–250 Denerim** (GM decides)
- Characters lacking weapon/armor **Competency** suffer **Hindrance** on Attack or Defense rolls
- **Dual wielding**: requires Competency in the weapon class one step above the two weapons used; damage die increases by one step (no extra attacks)

### Artifact Limit
- Equipping too many magical items causes Hindrance on all actions
- **Level 1**: max 1 equipped Artifact
- Capacity increases with leveling (per class advancement table)

## Growing in Power

| Advancement Type | Description |
|-----------------|-------------|
| **HP Boost** | Max HP increases by (max Recuperation Die value + MIGHT) |
| **Core Path Point** | +1 point to apply to existing or new Core Path |
| **Attribute Boost** | +1 to any one Attribute permanently |
| **Recuperation** | +1 to max Recuperations |
| **General Perk** | Select 1 perk from the General Perks list |
| **Artifact Capacity** | +1 to max equipped Artifacts |
| **Tier I Token** | Choose 1 new Tier I power OR 1 upgrade to existing Tier I power |
| **Tier II Token** | Choose 1 new Tier II power OR 1 upgrade to existing Tier II power |
| **AR/DR Boost** | +1 to Attack Rating and Defense Rating (at specific levels) |

### XP and Leveling
- Characters gain XP from defeating enemies and completing milestones
- XP thresholds and level cap determined by the GM Guide (Chapter IX)
