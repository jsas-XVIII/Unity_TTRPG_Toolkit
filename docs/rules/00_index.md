## Key Concepts Quick Reference

- **Core Roll**: 2d10 + Attribute + Bonuses vs. Target Number (TN)
- **Benefit**: Roll 3d10, drop lowest | **Hindrance**: Roll 3d10, drop highest
- **Massive Hit**: Rolling double 10s → triple base damage die (single target) or max damage (AoE)
- **Recharge**: Rolling any doubles on Attack or Defense roll → recharge Class Resource (roll recharge die)
- **Half Level (HL)**: Half of current character level, minimum 1, always round down
- **Armor Value (AV)**: Reduces Physical damage received per strike by AV amount
- **Ruin**: GM resource that accumulates over time and from player actions; spent to trigger events
